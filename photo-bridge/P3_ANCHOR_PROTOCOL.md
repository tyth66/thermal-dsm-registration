# P3 独立验收协议

## 0. 目的

把“内部留出变好”与“真实几何正确”分开验证。P3 不参与 P0–P2 调参；锚点在参数冻结后打开。

## 1. 冻结

在打开锚点前固定：

- 代码提交号；
- 算法配置：domain_mode、tile_m、step_m、L、lambda、ridge、P1/P2 开关；
- 参与比较的模型：baseline、P0-MAD、P0-mode；
- 锚点清单的哈希。

冻结后不允许根据 P3 结果修改锚点标注或评价样本。

## 2. Gate 1：DSM–DSM 平面配准

### 2.1 锚点要求

- 非周期：建筑角点、道路交点、阵列外边界、不规则地物；
- 独立于 ECC/RBF 拟合；
- 覆盖中心、边缘、稀疏区，以及 mode 过滤前后变化明显的区域；
- 同一批锚点用于 baseline、P0-MAD、P0-mode；
- 不支持预测的锚点保留，计入覆盖率，不删除。

### 2.2 锚点清单字段

每行至少包含：

- station
- anchor_id
- anchor_type
- visible_e, visible_n
- thermal_e_ref, thermal_n_ref
- reference_uncertainty_m
- region: center / edge / sparse / mode_changed
- source
- measured_at
- operator
- sealed: true

### 2.3 评价

对每个锚点保留有符号误差：

e_j = f(p_v,j) - p_t,j^ref

报告：

- 有符号 e_e、e_n 的均值与方向性；
- 范数 P50/P95/最大值；
- 分区域（中心/边缘/稀疏/mode_changed）统计；
- 空间块 Bootstrap 置信区间，块按区域划分；
- C_supported = 满足支撑条件的面板数 / 全部待映射面板数；
- 不支持预测的锚点数量与位置。

禁止只在被新算法支持的面板上统计精度。

### 2.4 通过条件

- 同一锚点集上，P0-mode 的 P95 不差于 baseline；
- C_supported 不显著下降；
- 不存在新的区域性系统偏移；
- 若 P0-mode 精度改善但覆盖显著下降，进入 P0-2c 覆盖恢复，而不是直接通过。

## 3. Gate 2：V5 原始热像投影

只有在 Gate 1 通过后执行。

### 3.1 输入

- 面板三维坐标；
- 热相机内参 K_t、外参 R_t,t_t；
- 畸变模型与图像坐标域；
- 原始热像与独立影像标注。

### 3.2 投影

q = pi(K_t, R_t, t_t, X)

### 3.3 误差分解

Delta q ≈ J_p Delta p + J_z Delta z + J_theta Delta theta

其中：

- Delta p：DSM–DSM 平面映射误差；
- Delta z：面板三维高程误差；
- Delta theta：热相机内外参误差。

### 3.4 通过条件

- 原片投影误差与独立标注一致；
- 不出现“DSM 平面场准确、但原片投影仍偏”的未解释误差；
- 若 Gate 1 通过而 Gate 2 失败，优先查三维高程/相机姿态/投影链，不回退调 RBF。

## 4. 判定表

| 结果 | 行动 |
|---|---|
| mode 外部精度改善、覆盖稳定 | 保留 P0-2b 默认 |
| mode 精度改善、边缘大量失去支撑 | 启动 P0-2c 覆盖恢复 |
| mode 内部改善、外部变差 | 重查模式选择与 coherent alias |
| DSM 锚点通过、V5 原片误差大 | 查三维高程、相机姿态、投影链 |
| DSM 与 V5 均通过 | 再做不确定性标定与生产准入 |
| 锚点不足以区分方案 | 保留现有默认，不继续依据内部指标改模型 |

## 7. 轮廓锚定试点（247，2026-11-21）

### 7.1 做法

- 源轮廓：把当前组件（面板）的可见光角点栅格化、闭运算、取连通外轮廓；
- 目标轮廓：热像 DSM 高度阈值，p25 + 0.5*(p50-p25)=13.69 m，闭/开运算后取外轮廓；
- 评价：把源轮廓按场映射到热像 EN，计算到匹配目标轮廓的最近边界距离。

### 7.2 结果

| 场 | 均值/m | P50/m | P95/m | max/m |
|---|---|---|---|---|
| P0-MAD | 0.280 | 0.209 | 0.822 | 2.292 |
| P0-mode | 0.261 | 0.200 | 0.707 | 2.288 |

- mode 的边界误差略低，但不构成内部几何正确性的证明；
- 边界是一维约束，内部低频形变仍不可见；
- 目标轮廓来自热像 DSM 高度，和 ECC 不同信号，但不是完全独立数据源。

### 7.3 141/290 的限制

同一高度阈值在 141/290 会混入地形、建筑和成片背景：

- 141 产生 13 个轮廓，主轮廓面积与阵列数不匹配；
- 290 产生 2 个轮廓，最大轮廓 7161 m²，明显包含非阵列区域。

因此轮廓锚定目前只能作为 247 的 **Gate 0 辅助检查**，不能替代内部独立锚点。

### 7.4 结论

- 轮廓锚定可以用于检查全局边界/平移/尺度；
- 不能单独作为 Gate 1 的验收；
- 141/290 需要人工边界点或面板分割，才能进入同一流程。
