# 边界位移外推问题与处理方案

状态：当前正式边界模型已落地并通过验收；仍保留样本内残差与顶部/底部少量残余  
适用对象：可见光 DSM → 热像 DSM 平面位移场（当前单一路径模型）  
样例：run 296，8295 个 panel，238 个 array

当前正式实现与参数见 [CURRENT_ALGORITHM.md](CURRENT_ALGORITHM.md)。

## 1. 问题摘要

当前位移场由两部分组成：

\[
T(p)=p+f(p)
\]

\[
f(p)=B(p-p_c)+t_0+g(p)
\]

- \(B(p-p_c)+t_0\)：全局相似位移；
- \(g(p)\)：RBF 局部残差。

边界处的问题不是“位移完全由 RBF 估计”，而是：

\[
\boxed{
\text{边界缺少局部残差观测支撑，}g(p)\text{ 被衰减到接近 0，}
}
\]

\[
\boxed{
\text{最终位移主要由全局 affine 外推得到。}
}
\]

因此边界误差可能表现为：

- 外推不足：真实局部残差仍在变化，但 \(g(p)\) 被压小；
- 外推过多：边界观测不足，affine 或线性尾把噪声放大。

具体方向取决于真实残差趋势，不能只用“算法减直接映射”的无符号差异判断。

## 2. 观测证据

### 2.1 边缘支撑衰减

run 296 按热像图像边界距离统计：

| 离边界 | 组件数 | 平均 field weight | 平均 \|算法−直接\| | conservative |
|---|---:|---:|---:|---:|
| 5–10 m | 73 | 0.277 | 0.443 m | 100% |
| 10–20 m | 212 | 0.324 | 0.437 m | 100% |
| 20–40 m | 2820 | 0.388 | 0.431 m | 99.3% |
| 40–80 m | 3180 | 0.471 | 0.383 m | 95.1% |
| 80–160 m | 2010 | 0.512 | 0.233 m | 99.8% |

相关系数：

- 边界距离 vs `field_weight`：**+0.786**
- 边界距离 vs `\|算法−直接\|`：**−0.627**

说明越靠近边界，RBF 密度越低，算法修正与直接映射的差异越大。

这里的“算法−直接”只是差异量，不是几何误差真值。

### 2.2 方向性

按最近边界方向统计平均修正量：

| 边界 | 5–20 m | 20–40 m | 现象 |
|---|---:|---:|---|
| 顶部 | 0.466 m | 0.522 m | 边缘修正小于向内趋势，偏欠外推 |
| 左侧 | 0.412 m | 0.446 m | 偏欠外推 |
| 底部 | 0.467 m | 0.455 m | 略高，方向不一致 |
| 右侧 | 0.215 m | 0.162 m | 样本少，略高 |

该表是初版无符号观测。方向的最终口径以用户视觉/生产对照为准：顶部、底部欠外推，左侧、右侧正常。

结论：

\[
\boxed{
\text{边界外推方向和幅度没有被观测约束，不能假设统一是“过多”或“不足”。}
}
\]

### 2.3 置信度失真

- 285 个 <20 m 边缘组件全部 `conservative_valid=1`；
- 393 个 `field_weight<0.30` 的组件全部 `conservative_valid=1`；
- `field_weight` 最小值 0.243，内部中位数 0.456。

当前交付标记高估了边缘可信度。

## 3. 根因

### 3.1 Tile 网格只有完整块

[dsm_registration.py](registration_algorithms/dsm_registration.py) 的 tile 起点：

    range(0, height - tile + 1, step)

完整 tile 的边缘中心仍距离图像边界约 tile/2。边界外侧没有观测，边界点只有向内单侧支撑。

本次结果：

- tile = 40 m，step = 20 m；
- 原始记录 134 个；
- accepted 101 个；
- ambiguous 33 个。

### 3.2 RBF 在支撑外被强制衰减

[residual_model.py](registration_algorithms/residual_model.py) 明确让 RBF 残差在支撑外衰减到零：

    The residual model decays to zero outside the tile support

边界处：

\[
g(p)\to0
\]

于是退化为：

\[
d_{\text{edge}}(p)\approx Ap+b
\]

如果真实残差在边界继续变化，这个退化结果可能表现为欠外推；若 affine 本身在边界被噪声推动，也可能表现为过外推。方向必须用有符号法向误差判断。

### 3.3 有效性门限只看最近 tile

[forward_mapping.py](registration_algorithms/forward_mapping.py) 当前：

\[
field\_valid(p)=[\min_i\|p-p_i\|\le 30\text{ m}]
\]

它不检查：

- 支撑是否单侧；
- `field_weight` 是否过低；
- 有效观测数；
- 支撑协方差/各向异性；
- 面板是否在观测凸包之外。

本次 `nearest_tile_m` 中位数约 9.8 m，边缘面板最近 tile 约 12–13 m，因此全部通过 30 m 门限，尽管 `field_weight` 只有 0.28 左右。

### 3.4 更小的 tile 不是充分修复

20 m tile / 10 m step 结果：

- accepted 407；
- conservative 8293；
- 边缘 `\|算法−直接\|` 没有下降，部分区间反而更大。

原因仍然是：边界外侧没有观测；更细 tile 只增加局部敏感性，没有补上边界条件。

## 4. 处理原则

\[
\boxed{
\text{把边界当成需要估计的边界条件，而不是固定衰减到零。}
}
\]

核心三件事：

1. 边界附近增加观测；
2. 用受控的法向线性尾代替强制 zero；
3. 单独输出边界置信度（该字段未采用，已从当前实现移除），并做边界留出验证。

## 5. 方案

### 5.1 增加边界锚定观测

增加以下任一或组合：

- 以左/右/上/下边界为中心的半块 tile；
- 边界处额外重叠 tile；
- 边界带独立配准。

目标：让边界点拥有内侧 + 边界附近的观测，缩短外推距离。

不要简单降低 `valid_fraction` 门槛；半块 tile 需要独立的掩膜和 ECC 处理。

### 5.2 边界法向线性尾 + 自适应收缩

内部保持 RBF。进入边界带后，用局部法向趋势：

\[
g_b(p)=g(p_0)+\nabla_n g(p_0)\,(s-s_0)
\]

其中：

- \(s\)：到边界的法向距离；
- \(\nabla_n g\)：由内侧 10–40 m 的 accepted tile 残差估计；
- 只沿法向外推，不沿切向自由外推。

再加收缩：

\[
\tilde g(p)=\lambda(p)g_b(p)+(1-\lambda(p))\bar g
\]

- \(\lambda=1\)：完全信任线性尾；
- \(\lambda=0\)：退回内部均值；
- \(\lambda\) 由支撑质量、法向覆盖、斜率方差决定，不写死。

这样：

- 欠外推时，线性尾补上局部趋势；
- 过外推时，收缩和斜率上限压住噪声。

### 5.3 边界置信度（未采用，已移除）

曾计划增加边界置信度 \(C_e\) 并纳入交付门限，但该字段没有完成标定，正式模型也没有把它用于 `conservative`。2026-11-24 已从代码和输出中移除 `edge_confidence` 及相关的低置信统计；本节的 \(C_e\) 仅作为未采用方案保留，不代表当前实现。

### 5.4 边界留出验证

这是决定“外推过多还是不足”的关键。

对每个站：

1. 遮住最外侧 20–40 m；
2. 用内部数据拟合；
3. 预测被遮住的边界带；
4. 比较四种策略：

   - 常数/affine；
   - 当前 RBF 零衰减；
   - 法向线性尾；
   - 收缩线性尾。

评价使用有符号法向误差：

\[
e_n=(d_{\text{pred}}-d_{\text{ref}})\cdot n
\]

- \(e_n>0\)：向外外推过多；
- \(e_n<0\)：外推不足。

按上/下/左/右分别统计，不做一个全局参数。

最终还需要独立锚点或生产投影结果验证；直接映射只能作为差异参考，不是几何真值。

## 6. 实施顺序

1. **边界留出验证**：先量化每个边的有符号法向误差，确认欠/过。
2. **边界锚定 tile**：补边界观测，缩短外推距离。
3. **法向线性尾 + 收缩**：替换强制 zero 衰减。
4. **边界置信度（未采用）**：曾计划把低支撑边缘降级；当前不输出该字段，也不改变交付口径。
5. **回归验证**：141 / 247 / 290 / 296，内部不退化，边界有符号偏差下降。

验收标准：

- 边界 signed normal bias 明显下降；
- 边界 MAE 不高于当前算法；
- 内部映射无回归；
- 结果可解释、可复现。

## 7. 不采用的做法

- 只降低 `field_max_distance`：会拒绝边缘，但不修复边界条件；
- 只缩小 tile：边界外侧仍无观测，20 m 实验已证明不够；
- 全局高阶多项式外推：边界易振荡；
- 固定边缘平移补偿：修一侧会破坏另一侧；
- 用无符号“算法−直接”差异判断过/欠：方向信息丢失。

## 8. 当前正式边界模型

当前实现位于 registration_algorithms/boundary_field.py：

- 边界残差：r_i = d_i - d_c(p_w,i)；
- 按边、按切向 bin 拟合局部残差；
- 每个 bin 6 个系数；
- 4 条边共用同一套局部模型；
- edge_distance_m 从热像栅格边界起算；
- 边界衰减为归一化 Gaussian：

alpha(s) = (exp(-s^2/(2T^2)) - exp(-2)) / (1 - exp(-2)), 0 <= s <= 2T

当前参数：

| 参数 | 值 |
|---|---:|
| tile T | 29.6 m |
| 边界 bin | 2T = 59.2 m |
| 局部半窗 | 2T = 59.2 m |
| 拟合 taper | 4T = 118.4 m |
| 最小局部 tile | 4 |
| 局部 ridge | 0.01 |
| 边界衰减 | Gaussian sigma=T，范围 2T |

run 296 正式结果：

- accepted tile：260；
- 应用边界尾点位：15,430；
- conservative 点位：41,419 / 41,475；
- conservative 组件：8,293 / 8,295；
- 目标无覆盖点位：56。

边界验收（修正前后 signed normal residual）：

| 边界 | 修正前 mean | 修正后 mean |
|---|---:|---:|
| 左侧 | -0.0131 m | -0.0112 m |
| 右侧 | -0.0175 m | -0.0047 m |
| 底部 | +0.1533 m | +0.0549 m |
| 顶部 | +0.0480 m | +0.0168 m |

内部 >2T 的区域位移变化为 0，边界修正没有泄漏到内部。

## 9. 当前状态

- 当前边界模型已通过验收并进入正式交付；
- `edge_confidence` 已移除，边界模型不再输出置信度或低置信统计；
- 112 个测试通过；
- 顶部/底部 bias 显著下降；
- 仍存在顶部 +1.7 cm、底部 +5.5 cm 的残余；
- 边界残差仍是样本内残差，后续可用 grouped cross-fit 改进。

### 9.1 与全原始候选联合模型的关系

在联合模型中，边界 tile 的有效质量下降会导致：

\[
m_i\to0,\qquad W_i\to0
\]

边界 RBF 系数失去局部数据支撑后，在零均值先验约束下继续收缩：

\[
g(p)\to0,\qquad f(p)\approx B(p-p_c)+t_0
\]

因此 outlier 模型可以阻止错误边界观测拉偏场，但也可能加剧边界局部残差欠拟合。这不是 outlier 模型错误，而是空间支撑不足导致的不可辨识性。

边界输出应同时包含：

\[
f(p),\quad \Sigma_f(p),\quad \operatorname{support}(p)
\]

并区分“数据驱动”“歧义”“邻域/先验主导”“全局外推”。局部后验方差小可能只是先验强，不能单独作为精度证据。
