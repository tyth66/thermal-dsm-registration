# V3-B：247 固定空间评价与 Prior=1 m 归因

状态：只读内部评价，不改变 V2 默认。  
参考代码：154c0fb  
测试：121 passed

## 1. 方法

为消除“不同 accepted 样本”造成的比较偏差，使用固定评价点：

- 参考观测：247 当前默认 prior=2 m 的 39 条 accepted；
- 评价点：这 39 条观测的中心；
- 固定空间划分：按 DSM 重叠区中心分成 4 个固定象限；
- 对每个候选：
  - 只在其余三个象限的候选 accepted 观测上拟合场；
  - 在同一批参考评价点上预测；
  - 计算误差和 field_supported 覆盖。

这是一个**固定 ECC 参考**，不是几何真值，也不是 V2 场预测；但它仍然与 V2 观测集合相关，存在内部偏置。

## 2. 固定评价结果

| Prior | accepted | 四象限误差 | 四象限支持覆盖 | 覆盖合计 |
|---:|---:|---|---|---:|
| 1.0 | 56 | 0.741 / 0.468 / 0.837 / 0.324 | 3 / 17 / 5 / 10 | 35 |
| 2.0 | 39 | 0.418 / 0.461 / 0.541 / 0.410 | 2 / 14 / 6 / 10 | 32 |

结果：

- prior=1 m 在固定评价点上只多覆盖 3 个点；
- 两个象限误差变差，一个象限变好；
- 总体没有稳定改善；
- accepted 从 39 增加到 56，但增益没有转化为稳定的空间覆盖或误差下降。

## 3. Prior=1 m 新增观测归因

按瓦片中心精确匹配，prior=1 m 相对 prior=2 m 新增 20 条 accepted：

| 指标 | 值 |
|---|---:|
| 新增 accepted | 20 |
| 被 prior=2 场支持 | 20 / 20 |
| 象限分布 | 4 / 6 / 3 / 7 |
| ambiguous | 0 |
| alias_conflict | 0 |
| 平均 cc | 0.916 |
| 平均 margin | 0.95 |
| 到最近观测中位距离 | 5.2 m |
| dx 中位 | -0.29 m |
| dy 中位 | 0.02 m |

结论：

- 新增观测不是“新区域”，而是**已有支持区内的高置信、近零位移观测**；
- 它们与 prior=2 场一致，因此被场支持；
- 这些观测增加了 accepted 数量，但没有扩展有效空间覆盖；
- 它们可能只是提供了冗余约束，甚至引入轻微偏差，导致固定评价误差没有改善。

这解释了为什么 accepted 39→56，但误差没有同步下降。

## 4. 与 B1/B3/B4 的关系

同样的混杂因素也存在于：

- Tile 16 m：留出点只有 9，两个象限为空；
- Tile 20.8 m：留出点只有 3；
- Grid 0.05 m：留出点 29，但网格变化同时改变观测中心；
- Sigma 2 m：留出点 24。

因此，这些总均值只能作为敏感性证据，不能作为参数替换依据。

## 5. 限制

- 评价点来自 V2/prior=2 的 accepted 观测，存在内部偏置；
- 参考位移来自 ECC，不是几何真值；
- 固定评价点的空间分布本身受参考观测限制；
- 这不是独立锚点验证，只是更公平的内部比较。

## 6. 下一步

1. 用**固定高密度 ECC 参考**或**合成已知位移**建立独立评价点，不再以 V2 accepted 为唯一参考；
2. 对 B1/B3/B4 全部使用同一批固定评价点；
3. 同时报告：
   - 固定评价点误差；
   - field_supported 覆盖；
   - 新增/消失观测的象限与最近邻距离；
   - ambiguous/alias 分布；
4. 若固定评价仍无法区分候选，保留 V2；
5. 不启动 V3-C。

## 7. 当前判断

Prior=1 m 的 accepted 增益主要是**冗余观测**，不是新增空间约束。  
因此没有理由将其设为默认；V2 继续冻结 prior=2 m。

这轮最重要的结论不是“prior=1 好/坏”，而是：

\[
\boxed{
\text{accepted 数量增加}
\;\neq\;
\text{有效空间约束增加}
}
\]
