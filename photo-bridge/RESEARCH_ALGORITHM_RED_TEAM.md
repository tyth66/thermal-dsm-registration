## 1. 被攻击的方案（原文核心）

原方案 P0-1：用掩膜 ECC 替代/补充当前 ECC，并把 0.8 联合支撑门槛降到 0.6/0.5；依据是 247 留块 0.504→0.365、留一 0.472→0.340；290 留一 0.198→0.146；141 留块 0.251→0.218。验收线：247 留块 ≤0.40、290 留一 ≤0.15、141 留块 ≤0.23 且留一 P95 ≤0.45。

最强反对者从三个层面攻击：

1. **统计层面**：合并 P50 掩盖单折异质性；阈值是在同一批数据上选的；LOO/留块是自洽指标，不是绝对精度。
2. **机制层面**：掩膜 ECC 会改变 CC 权重，把低支撑/边缘瓦片加权；这可能帮助插值却损害块外推；247 的病因是局部多峰，不是样本量。
3. **产品层面**：141 是唯一有独立热像投影验证的站（1× 纠正 69.8 vs 不纠正 38.2），0.6 会改变它却未重跑 V5；290 的面板位移是修正量的 41%，超过其 jackknife 0.045 m。

## 2. 七条攻击与证据

### 攻击 1：141 的“块收益”疑似单折伪影

按 PCA 四折分解（每折约 20–26 个瓦片），块误差 P50：

| 阈值 | 折 0 | 折 1 | 折 2 | 折 3 | 合并 P50 |
|---|---|---|---|---|---|
| 0.8 | **0.567** | 0.105 | 0.161 | **0.239** | 0.251 |
| 0.6 | **0.228** | 0.155 | 0.213 | **0.260** | 0.218 |
| 0.5 | 0.247 | 0.152 | 0.182 | 0.462 | 0.271 |

- 0.6 的合并改善几乎全部来自折 0（0.567→0.228）；折 1/2/3 分别 0.105→0.155、0.161→0.213、0.239→0.260，**3/4 折变差**。
- 这是典型的“单折离群值驱动合并均值”：折 0 有几个局部不一致瓦片，0.6 的额外低支撑瓦片恰好平滑了它们；其他折没有这种受益。
- 结论：固定 PCA 分区下，**141 的合并收益确实由单折驱动**；用这个合并 P50 证明“141 全面改善”是误导。但这不等于 0.6 完全无效——见下面对手的反例复核。

### 攻击 1 的反驳：7 角度分区复核（对手也未完全正确）

把 PCA 主轴旋转 −30°…+30°（7 个角度），每个角度沿投影切 4 个等数量块，重做 0.8 vs 0.6 的块留出：

| 站点 | 0.8 均值 [min,max] | 0.6 均值 [min,max] | 0.6 胜出角度 | 0.6−0.8 配对差 |
|---|---|---|---|---|
| 141 | 0.263 [0.221,0.332] | **0.229 [0.196,0.288]** | **5/7** | −0.085, +0.014, +0.019, −0.032, −0.055, −0.079, −0.026 |
| 247 | 0.485 [0.427,0.578] | **0.419 [0.341,0.492]** | **5/7** | +0.051, +0.059, −0.068, −0.139, −0.237, −0.123, −0.006 |
| 290 | 0.189 [0.189,0.189] | 0.184 [0.172,0.192] | 6/7 | −0.002, −0.002, −0.002, −0.017, −0.017, −0.002, +0.003 |

- **141/247 不是“纯单折伪影”**：0.6 在 5/7 个分区方向平均更好（141 −13%、247 −14%），但在 2/7 个方向变差（141 +0.014/+0.019；247 +0.051/+0.059）。固定 4 折的“3/4 折变差”是那个方向的特例，不能外推为“0.6 全面无效”。
- **290 的块收益可以忽略**：0.189→0.184（−3%），6/7 方向但幅度在噪声内；结合面板 Δ 0.051 m（34%），290 不应改。
- **正确的结论**：原方案“合并 P50 改善”是真的平均效应，但**方向依赖且没有 V5**；对手“141 完全无效”也过头。0.6 是 141/247 的**候选**，不是 141/247 的产品结论，更不是 290 的依据。
- **方法学教训**：固定 4 折的合并 P50 既可能被单折放大，也可能被单折掩盖；应报告多方向分区的分布（如 7 角度）与配对差，而不是一个数。

### 攻击 2：掩膜 ECC 不是稳定改进，反而可能恶化块外推

2×2 析因（掩膜 on/off × 阈值 0.8/0.6），同一批瓦片、同一域、同一场参数：

| 站点 | 组合 | 留一 P50/P95 | 留块 P50/P95 | 面板 Δ P50/max |
|---|---|---|---|---|
| 141 | nomask 0.8 | 0.141 / 0.421 | 0.251 / 0.790 | 0 |
| 141 | mask 0.8 | 0.146 / 0.420 | 0.249 / 0.764 | 0.0004 / 0.0025 |
| 141 | nomask 0.6 | 0.140 / 0.642 | 0.218 / 0.609 | 0.036 / 0.123 |
| 141 | mask 0.6 | 0.136 / **1.119** | 0.234 / 1.193 | 0.030 / 0.135 |
| 247 | nomask 0.8 | 0.472 / 1.773 | **0.504** / 1.672 | 0 |
| 247 | mask 0.8 | 0.421 / 1.772 | **0.638** / 1.672 | 0.017 / 0.093 |
| 247 | nomask 0.6 | 0.340 / 1.578 | **0.365** / 1.453 | 0.059 / 0.143 |
| 247 | mask 0.6 | 0.336 / 1.588 | **0.393** / 1.497 | 0.061 / 0.145 |
| 290 | nomask 0.8 | 0.198 / 0.444 | 0.189 / 0.423 | 0 |
| 290 | mask 0.8 | 0.197 / 0.436 | 0.185 / 0.436 | 0.004 / 0.007 |
| 290 | nomask 0.6 | 0.146 / 0.364 | 0.172 / 0.414 | 0.051 / 0.120 |
| 290 | mask 0.6 | 0.146 / 0.368 | 0.167 / 0.407 | 0.055 / 0.121 |

关键反例：

- **247 mask@0.8：留一从 0.472 改善到 0.421，但留块从 0.504 恶化到 0.638。** 同一改动在两个指标上方向相反，说明掩膜 ECC 提高了边缘瓦片的 CC 权重，让场更贴合局部观测、却损害块外推。用留一单独证明掩膜有效是错误归因。
- **247 mask@0.6：留块 0.393 比 nomask@0.6 的 0.365 差**；掩膜并没有叠加阈值收益。
- **141 mask@0.6：留一 P95 从 0.642 恶化到 1.119**；掩膜把尾部放大了一倍。
- 290 掩膜基本无影响（0.8 时留块 0.189→0.185，面板 0.004）。

结论：**掩膜 ECC 不能被列为 P0 修复**；它最多是一个需要独立验证的实验，且必须同时报告留块，而不能只看留一/CC。

### 攻击 3：自洽指标不是精度，290 的面板敏感性尤其危险

- 290 从 0.8 到 0.6：面板 Δ P50 0.051 m（34% 的 0.152 m 修正）、max 0.120 m；到 0.5：0.063 m（41%），大于其 jackknife 0.045 m。
- 247 从 0.8 到 0.6：面板 Δ 0.059 m（13% 的 0.439 m），max 0.143 m。
- 141 从 0.8 到 0.6：面板 Δ 0.036 m（7%），但留一 P95 0.421→0.642。
- 这些改动都没有 247/290 的独立热像投影验证；141 有 V5，但没有重跑 0.6 版本。

最强反对者会说：**如果修正量本身只有 0.15 m（290），却因为一个自洽指标把它改 0.063 m，这是拿产品赌一个未经验证的统计改进。**

### 攻击 4：瓦片重叠让“更多观测”不等于“更多独立信息”

- step = tile/2：相邻瓦片有 **50% 面积重叠**（对角 25%）；留一瓦片的预测邻域与训练观测高度相关，LOO 误差本身偏乐观。
- 141：83 个 40×40 m 瓦片覆盖 132,800 m²，站点面积 60,418 m²，**2.2× 冗余**；所谓的 83 个观测不是 83 个独立样本。
- 247：64×108.16=6,922 m² vs 5,152 m²，1.34× 冗余。
- 290：22×1,260=27,726 m² vs 40,199 m²，覆盖只有 0.69×（稀疏）。
- 0.6 增加的瓦片多在边缘，与已有瓦片重叠；LOO 改善可能来自方差下降（更多邻居），而不是偏差下降（更接近真值）。合并 LOO 无法区分这两者。

### 攻击 5：247 的病因是局部多峰，不是样本量

- 247 的 64 个入模瓦片中，**27 个**与 8 邻域中值差 >0.5 m（15 个 >1 m，3 个 >2 m）；这些样本的 CC 0.946–0.979。
- 0.6 新增瓦片后，85 个中仍有 **31 个** >0.5 m（36%），比例没有改善。
- 掩膜 ECC 抽查：CC 从 0.706/0.796/0.545 提升到 0.935/0.974/0.649，但同一瓦片的粗/单位初值仍出现 **1.5–7 px**（0.15–0.7 m）分歧。
- 结论：**掩膜提升 CC 不等于解决多峰；降低门槛增加的是“更多同质噪声”，不是“更多真值”。** 247 的 0.6 改善是净效应（3/4 折），但 fold 1 从 0.348 恶化到 0.446，仍然不稳。

### 攻击 6：141 是唯一有外部验证的站，改动它风险最大

- 既有 V5 证据：141 的 1× 纠正热像梯度 69.8，不纠正 38.2、0.5× 39.4、2× 29.2、垂直 31.4、反向 30.8。**当前 141 的场是被独立数据正面验证过的。**
- 0.6/覆盖率加权会把 141 的面板位置改 0.036/0.023 m；V5 是否能分辨这个量级未知。原方案虽然写了“141 V5 ≥69.8”的验收线，但在推荐 P0 时并没有跑 V5，属于“先推荐、后验证”。
- 更严重的是，0.6 让 141 的留一 P95 从 0.421 变 0.642；原方案的验收线“141 留一 P95 ≤0.45”自己就把 0.6 判为不通过。**原方案内部自相矛盾。**

### 攻击 7：用一个硬阈值替换另一个硬阈值，违背“纯估计器”哲学

- 0.8 是硬门槛；0.6/0.5 也是硬门槛，只是在同一批数据上重新选了一个值。选择本身没有可迁移的规则。
- 更好的形式是**连续覆盖率权重**：保留 0.5 的最低纳入，权重 w = valid_fraction（或 w = valid_fraction²），让低支撑瓦片以较小权重参与，而不是被一刀切丢弃。
- 247 的实验支持这一点：soft0.5_vf 的留一 0.338 / 留块 0.359 / 面板 Δ 0.024，**全面优于 hard0.6 的 0.355 / 0.365 / 0.039**；soft0.5_vf2 的面板 Δ 更小（0.021），但留块 0.421 变差——说明权重形式要选，不能随便平方。

### 攻击 7 的反驳/升级：覆盖率权重的 7 角度复核

固定 0.8 域（生产域），对同一批 vf≥0.5 的瓦片做 7 角度分区，比较 hard0.8、hard0.6、soft0.5_vf、soft0.5_vf2：

| 站点 | hard0.8 均值 | hard0.6 均值（胜/差/面板 Δ） | soft0.5_vf（胜/差/面板 Δ） | soft0.5_vf2（胜/差/面板 Δ） |
|---|---|---|---|---|
| 141 | 0.263 | 0.229（5/7，−0.035，0.036） | 0.245（5/7，−0.018，0.029） | **0.227（7/7，−0.037，0.023）** |
| 247 | 0.485 | 0.441（3/7，−0.044，0.039） | **0.411（7/7，−0.074，0.024）** | 0.424（5/7，−0.061，0.021） |
| 290 | 0.189 | 0.184（6/7，−0.006，0.051） | 0.173（7/7，−0.016，0.064） | 0.180（6/7，−0.010，0.061） |

- **更好的形式确实是连续权重，而不是硬阈值**：141 的 soft0.5_vf2 **7/7 角度改善**（均值 −0.037、面板 Δ 0.023），247 的 soft0.5_vf **7/7 改善**（均值 −0.074、面板 Δ 0.024）。hard0.6 在 141 只有 5/7、在 247 的固定域下只有 3/7，且面板变化更大。
- **这同时解决了“141 单折伪影”**：soft0.5_vf2 在 7 个方向全部改善，说明平均收益不是单折驱动的；之前的“3/4 折变差”是固定 PCA 分区 + 硬阈值的特例。
- **290 仍不能改**：soft0.5_vf 虽然 7/7，但块收益只有 8.5%，面板 Δ 0.064 m（42% 的 0.152 m 修正）；hard0.6 面板 0.051。两者的产品风险都高于收益，保留 0.8。
- **注意口径**：本表的 hard0.6 用固定 0.8 域；若按 hard0.6 自己重估域，247 的 7 角度为 5/7（前表）。覆盖率权重的产品语义是“保留 0.8 域 + 连续降权”，因此本表是更相关的比较。

## 4. 重新评估：哪些部分活下来

### 4.1 撤回与降级

## 6. 什么能推翻修订方案（证伪条件）

1. **V5 反证**：141 的 soft/0.6 变体热像梯度低于 69.8 → 保留现状；247/290 的 V5 若显示覆盖率权重变差 → 撤回。

## 7. 结论

- **原 P0-1 的掩膜部分被推翻**：247 mask@0.8 留块 0.504→0.638；141 mask@0.6 留一 P95 1.119；掩膜不叠加阈值收益。
- **原 P0-1 的硬阈值部分降级为候选**：141 5/7（−0.035）、247 固定域 3/7（自估域 5/7）、290 6/7 但仅 −0.006；面板 Δ 34–41%、无 V5；不能作为产品改动。
- **更好的解法**：保留 0.8 默认；141 用 soft0.5_vf2（7/7，−0.037）；247 用 soft0.5_vf（7/7，−0.074）；290 暂不改（soft 7/7、块收益 8.5%，但 V5 未完成）；所有留块指标逐折 + 7 角度分区报告；V5 作为有效性门槛；panel Δ 仅报告变更影响。
- **最强反对者留下的教训**：**固定分区的合并 P50 既可能被单折放大，也可能被单折掩盖；必须用多方向分区 + 配对差 + 外部 V5，才能判断一个“平均改善”是否可信。**
